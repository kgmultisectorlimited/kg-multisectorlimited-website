# KG MULTISECTOR LIMITED website

This is the company's static website for its Plumbing Works and Corporate Training divisions. It uses plain HTML, CSS, and image assets; there is no build step.

## Preview

Open `index.html` in a browser, or serve this folder with a local static web server.

## Publish with GitHub Pages

In the GitHub repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, then save. GitHub Pages will provide the public website URL after deployment.

Only publish this repository publicly if the company is comfortable making all included website content and images publicly accessible. Do not add private company documents or credentials.
